## Current thesis

APIs are naturally machine-consumable, usage-billable and scalable, making them strong infrastructure for agentic businesses. The constraint is choosing a lawful, valuable niche with recurring demand rather than building generic endpoints first.

## Supported evidence

- Usage/subscription billing maps well to recurring machine demand.
- Agents increasingly require reliable structured external data.
- Once a data pipeline is proven, marginal delivery can be highly automated.

## Key unknowns

- First lawful niche and source rights.
- Acquisition economics and developer adoption.
- Retention and data-maintenance burden.

## Minimum commercial test

Find one customer repeatedly paying labour/time for the same data task; expose only the minimum endpoint and require paid usage before broadening the API.
