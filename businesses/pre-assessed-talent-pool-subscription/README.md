# Pre-Assessed Talent Pool Subscription

**Stage:** Researching  
**Opportunity score:** 86/100

## Offer

A permissioned, maintained pool of candidates already screened/assessed for a narrow role family, available to employers on recurring access.

## Outcome sold

Shorter time-to-shortlist and lower repeated screening effort.

## Commercial model

Employer access subscription, potentially with placement/assessment upsells.

## Next action

Build a permissioned 100-candidate pilot in one role family and test employer willingness to subscribe.
