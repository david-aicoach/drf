## Current thesis

Talent Bridge already owns assessment architecture, pricing experience, report formats and AI-interview concepts, materially reducing product and go-to-market risk. The strongest model is subscription plus usage rather than one-off report generation.

## Supported evidence

- Existing Talent Bridge assessment/reporting assets provide a real proving ground.
- Employers already pay for assessment/evaluation work.
- Candidate evaluation workflows are highly automatable while still supporting human judgement.

## Key unknowns

- Self-service employer activation and conversion.
- Churn and recurring candidate volume.
- Enterprise integration/support burden and gross margin.

## Minimum commercial test

Package one employer-facing self-service pilot using current Talent Bridge IP. Measure candidates processed, repeat usage, support minutes, report acceptance and willingness to continue monthly.
