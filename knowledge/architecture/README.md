# Architecture

Durable DRF system design and rationale.

Architecture must explain why the chosen structure exists, what it replaces, major boundaries and how it supports measurable commercial execution without unnecessary complexity.

## Canonical commercial architecture

Start with:

`outcome-first-modular-revenue-architecture.md`

It governs the DRF commercial delivery model:

`Outcome × Niche × Customer Channel × System of Record × Agent Layer`

For UAE service businesses it also establishes the WhatsApp-first default and the rule that CRM, channel and agent vendors remain modular/replacement choices.
