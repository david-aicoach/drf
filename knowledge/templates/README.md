# Templates

Standard structures for recurring DRF outputs. Use only the files required by the current layer/proof stage; do not create paperwork before it buys a decision or evidence.

## Start here

1. [`drf-opportunity-factory-intake-prompt.md`](./drf-opportunity-factory-intake-prompt.md) — reusable founder-to-agent prompt. It also contains Discovery and Portfolio Refresh variants.
2. [`../../workflows/drf-opportunity-factory.md`](../../workflows/drf-opportunity-factory.md) — the one canonical end-to-end workflow.

## Three-layer DRF pack

### Layer 1 — Opportunity Discovery & Structural Selection

- [`revenue-opportunity-scan-card.md`](./revenue-opportunity-scan-card.md) — fast scan for high-volume opportunity discovery. [77.3] #80 will align it fully with Opportunity Score and External Market Proof.
- [`business-opportunity-readme.md`](./business-opportunity-readme.md) — short founder summary/current decision.
- [`business-opportunity-research.md`](./business-opportunity-research.md) — current full business research structure. [77.3] #80 will upgrade it into the complete V3 dossier.

### Layer 2 — Niche Selection & Commercial Underwriting

- [`revenue-blueprint-financial-model.xlsx`](./revenue-blueprint-financial-model.xlsx) — 12-month downside/base/upside model with capital, cash, ROI, payback, runway and founder-time returns.
- [`revenue-blueprint-financial-model.md`](./revenue-blueprint-financial-model.md) — financial-model definitions, inputs, formulas and decision rules.
- [`revenue-blueprint-investment-memo.md`](./revenue-blueprint-investment-memo.md) — detailed capital/decision memo where the stage requires it.
- [`business-benchmark-scorecard.md`](./business-benchmark-scorecard.md) — benchmark an existing business, department, bottleneck, pivot or added revenue model.

### Layer 3 — Structured Factory Output and optional Blueprint packaging

- [`revenue-blueprint-specification.md`](./revenue-blueprint-specification.md) — operating recipe and P3–P6 packaging/certification structure.
- [`revenue-blueprint-factory-dashboard.md`](./revenue-blueprint-factory-dashboard.md) — factory throughput, proof conversion, capital efficiency, portfolio cash and Blueprint revenue metrics.
- [`business-opportunity-worked-example-business-blueprints.md`](./business-opportunity-worked-example-business-blueprints.md) — Business Blueprints example showing Outcome × Niche → product format → channel portfolio, with external proof and DRF proof/capital kept separate.

## Canonical order

```text
LAYER 1 — SELECT THE BUSINESS
business opportunity → pain/outcome → successful operators
→ Opportunity Score → MRR → AI Autonomy → Evidence → Research → External Market Proof
→ Reject / Hold / Advance

LAYER 2 — SELECT THE TARGET AND DESIGN THE BUSINESS
rank niches → choose beachhead → reverse-engineer operator patterns
→ offer → pricing → GTM → delivery architecture → RBS → economics
→ DRF Proof → Stage → Capital → Next Proof

LAYER 3 — STRUCTURE THE FACTORY OUTPUT
founder-readable mini business plan → canonical portfolio data
→ execution plan → optional Business Blueprint packaging

EXECUTION
backtest → forward test → paid value → repeatability → scale
```
