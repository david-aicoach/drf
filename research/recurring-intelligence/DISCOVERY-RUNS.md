## Entry rules

- Status: `COMPLETED`, `PARTIAL`, `FAILED` or `SUPERSEDED`.
- Do not record planned but never-started work as a run.
- Link a detailed candidate/run record or GitHub Issue where material work occurred.
- `PARTIAL`/`FAILED` rows must state which canonical values remained unchanged.
- Do not infer successful discovery from the number of signals scanned.
- A zero in a count is valid only when observed; unavailable counts use `Unknown`.
