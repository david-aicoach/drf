# Guideline — Revenue First

## Principle

DRF exists to create and scale commercial traction, not to accumulate infrastructure.

```text
traction
before
build
```

## Default priority

```text
SELL
→ USE
→ INTEGRATE
→ AUTOMATE
→ BUILD
```

This is a decision heuristic, not an absolute sequence. Skip directly to a later step only when evidence shows it is necessary.

## Commercial proof ladder

```text
idea
→ target customer identified
→ real problem evidenced
→ offer stated
→ prospect conversation
→ qualified meeting / buying signal
→ proposal / checkout
→ cash collected
→ successful fulfilment
→ repeatability
→ scale
```

Do not treat these as equivalent:

- leads researched ≠ prospects contacted;
- prospects contacted ≠ positive replies;
- positive replies ≠ qualified meetings;
- meetings ≠ sales;
- sales ≠ collected cash;
- collected cash ≠ profitable repeatability.

## Build gate

Before optional build work, answer:

1. What current commercial blocker does this remove?
2. What is the smallest existing/native way to remove it?
3. What metric should improve if the build works?
4. What happens if we do nothing?

If those answers are weak, return to selling, research or an existing tool.
