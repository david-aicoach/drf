## Source-first reconciliation

- [ ] Read the current authoritative source before writing.
- [ ] Update the detailed source/evidence first.
- [ ] Update `OPPORTUNITIES.md` if Layer 1 fields changed.
- [ ] Update `NICHES.md` if ranked niche fields changed.
- [ ] Update current Layer 3 dossier/CURRENT if offer, price, GTM, delivery, RBS, Return, EMP, DRF Proof, Stage, Capital, Next Proof or readiness changed.
- [ ] Review every V3 founder field affected by the new evidence.

## V3 result — choose exactly one

### Option A — V3 fields changed

- [ ] Update `businesses/PORTFOLIO-V3.md` **last**.
- [ ] Confirm no unsupported score/proof movement was introduced.

### Option B — no V3 field changed

- [ ] Add a row to `businesses/V3-RECONCILIATIONS.md`.
- [ ] Record why the new evidence does not change a founder-facing V3 field.

## Proof integrity

- [ ] EMP and DRF Proof remain separate.
- [ ] Documentation/research did not raise DRF Proof by itself.
- [ ] Pending/Unknown/Not applicable were not converted to zero.
- [ ] Evidence freshness was reviewed.
- [ ] Next Proof remains explicit and bounded.

## Verification

- [ ] V3 register/reconciliation decision agrees with the current source.
- [ ] Dashboard source remains derived/read-only.
- [ ] Repository/software checks pass.
- [ ] Governing Issue records the V3 reconciliation result.
